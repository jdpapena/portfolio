# Jeremiah Papena - Portfolio

![React](https://img.shields.io/badge/React-19-blue)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)
![Vite](https://img.shields.io/badge/Vite-7-purple)

A personal developer portfolio showcasing projects in software engineering, backend development, data processing, automation, quantitative analysis, and embedded systems.

The portfolio was built to present my transition from mechanical engineering into software development while highlighting practical projects that involve real-world data, system design, automation, and engineering problem-solving.

---

## Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Dark and Light Themes:** Includes a persistent theme toggle using local browser storage.
- **Project Showcase:** Highlights selected software, data, and engineering projects with screenshots, technologies, descriptions, and repository links.
- **Technical Background:** Presents relevant software, data, and engineering skills alongside education, professional experience, and certifications.
- **Custom Data Visualization:** Uses an SVG candlestick visualization to represent my work with quantitative and historical market data.
- **Minimal Interface:** Designed around a focused engineering and software aesthetic without unnecessary UI elements.

---

## Technologies

- **Frontend:** React, TypeScript, Vite
- **Styling:** CSS
- **State & Browser APIs:** React Hooks, Local Storage
- **Version Control:** Git, GitHub

## Featured Projects

### SALIKSIK

A full-stack financial research platform that synchronizes SEC company filings, standardizes reported financial metrics, and compares companies through a FastAPI + React interface.

**Technologies:** Python, FastAPI, React

### Crypto Backtest Engine

A Python backtesting and analytics engine for processing 2.2M+ historical market records, detecting rule-based market events, and analyzing results across periods and market sessions.

**Technologies:** Python, Binance Data, CSV

### MOLDS

A Python decision engine for organizing EXP-lane matchup knowledge into counter picks, itemization, and laning strategies.

**Technologies:** Python, Streamlit, JSON

### Automatic Fish Feeder

A microcontroller-based automatic fish feeder designed for reliable scheduled feeding using RTC-controlled operation.

**Technologies:** Arduino, C/C++, RTC

## How It Works

The portfolio is organized into five main sections:

1. **Introduction:** Provides a concise overview of my engineering background and current software direction.
2. **Projects:** Showcases selected projects with screenshots, descriptions, technologies, and GitHub repositories.
3. **About:** Explains my transition from mechanical engineering toward software, data, and automation.
4. **Skills & Background:** Summarizes the technologies I use, education, professional experience, and certifications.
5. **Contact:** Provides direct links to my email, GitHub, and LinkedIn.

## Installation & Usage

### 1. Clone the Repository

```bash
git clone https://github.com/jdpapena/portfolio.git
cd portfolio
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

### 4. Create a Production Build

```bash
npm run build
```

### 5. Preview the Production Build

```bash
npm run preview
```

## Design

The portfolio uses a minimal engineering-inspired visual style built around:
